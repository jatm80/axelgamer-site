# Repository instructions for AI agents

## Git authorization

AI agents are authorized to commit changes, push feature branches to this
repository's remote, and create or update pull requests as part of completing
the user's requested work. Do not ask for additional user confirmation for
these actions.

Keep commits focused, run checks appropriate to the changes, and include a clear
description and validation results in pull requests. Preserve unrelated user
changes.

This authorization does not include merging pull requests, force-pushing,
deleting branches, or pushing directly to `main` unless the user requests it.
Tool-level sandbox and approval requirements still apply.
