Minecraft mods can add tiny map helpers, new creatures, wild machines, or enormous adventures. Getting one to start is less mysterious than it looks. The important bit is making sure every download matches.

This guide is for Minecraft Java Edition on a computer. Fabric is a mod loader, which means it helps Minecraft start and run mods. Fabric mods do not work with Bedrock Edition on consoles, phones, tablets, or Windows in Bedrock mode.

## Before you begin

Ask a parent or guardian before downloading or installing anything. You need a paid copy of Minecraft Java Edition, the official Minecraft Launcher, and permission to change files on the computer.

Back up any world you care about. Open Minecraft, select the world, choose Edit, then Make Backup. A broken or removed mod can sometimes damage a modded world, so test with a new world first.

## Install Fabric

1. Visit the official [Fabric website](https://fabricmc.net/use/installer/) and download the Fabric Installer. Avoid download buttons on random reposting sites.

2. Close Minecraft and the launcher. Open the installer, choose the Minecraft version you want, make sure Create Profile is selected, and install it.

3. Open the Minecraft Launcher. A new Fabric profile should appear. Start it once, then close the game. This creates the folders Fabric needs.

## Add one mod

1. Find a mod on [Modrinth](https://modrinth.com/mods) or [CurseForge](https://www.curseforge.com/minecraft). Read its page carefully.

2. Check three labels before downloading: Minecraft version, Java Edition, and Fabric. A mod made for another version or a loader such as Forge may not start.

3. Look for required dependencies. A dependency is another mod needed to make the first one work. Many Fabric mods need Fabric API, but only download it when the mod page or instructions say so.

4. Move the downloaded `.jar` file into your Minecraft `mods` folder. On Windows, it is usually inside `%appdata%\.minecraft`. On Mac, look in `~/Library/Application Support/minecraft`. On Linux, look in `~/.minecraft`.

5. Select the Fabric profile in the launcher and press Play. Create a fresh Creative world and check that the mod works before opening an important save.

## If Minecraft will not start

Do not panic and do not keep downloading mystery fixes. Read the error for a missing dependency or wrong version. Remove the newest mod from the `mods` folder and try again.

Keep each setup tidy. When Minecraft updates, wait until Fabric and your chosen mods list support for that exact version. Matching those labels is the difference between a brilliant modded afternoon and staring at an error screen.
