**Yes. Captain Toad: Treasure Tracker on Nintendo Switch supports two players on one console, including a co-op mode where both players explore the courses.** There is also an assist option in which one player handles the character while the other helps against enemies. [Nintendo Australia describes both options](https://www.nintendo.com/au/games/nintendo-switch/captain-toad-treasure-tracker/).

## Choose the kind of help your child wants

Two characters exploring together suits a pair who both want to take part in the puzzle. The assist option is useful when a child wants to lead while a parent helps clear trouble. Ask which arrangement sounds more fun before starting; a helper who solves every puzzle can leave the other player feeling like a passenger.

For a first session, give each player a job: one searches for a route and the other looks for treasure. Swap those jobs on the next course. If someone spots the solution first, try offering a clue rather than immediately showing the answer. That keeps the discovery shared.

## What do you need?

Use the Nintendo Switch version, install available software updates, and prepare a compatible controller for each player. A shared pair of Joy-Con gives each person one controller. TV or tabletop play makes it easier for both players to see the same puzzle; a Switch Lite needs separate compatible controllers for multiplayer. Nintendo's listing confirms local support for one or two players, so you do not need a second console for this setup.

Do not use an old Wii U or Nintendo 3DS guide to decide how this Switch version works. Nintendo also lists Switch 2 compatibility, but playing together on one original Switch is the setup covered here.

## A good first puzzle session

Start with a single course and leave optional treasure hunting for a return visit if either player loses patience. The aim can be finding a route together, rather than collecting everything before anyone is allowed to move on.
